# Tabeeb — Freelance Web Development Portfolio

A responsive portfolio website built with React, TypeScript, Vite, and Tailwind CSS. The site presents web development services, selected work, an interactive frontend case study, a clear project process, and a contact call to action.

## Live project

- **Website:** https://tabeeb1314.github.io/metricflow/
- **Repository:** https://github.com/tabeeb1314/metricflow

## What this portfolio demonstrates

- Responsive layout and mobile navigation
- Clear service positioning and calls to action
- Interactive dashboard with metric and date-range controls
- SVG chart rendering, simulated anomaly states, and client-side CSV export
- Project showcase and delivery-process sections
- Keyboard-friendly controls and reduced-motion styling
- GitHub Actions deployment to GitHub Pages

## Featured concept: MetricFlow

MetricFlow is a fictional analytics SaaS concept used to demonstrate frontend engineering and interface design. Its sample metrics, company data, pricing, and automated insights are illustrative only. It is not a live analytics product and has no real customers or production data integrations.

Other portfolio examples are also identified as concept work where applicable. No client testimonials, commercial outcomes, or paid engagements are claimed unless explicitly stated.

## Run locally

Requires a recent Node.js version.

```bash
git clone https://github.com/tabeeb1314/metricflow.git
cd metricflow
npm install
npm run dev
```

To create a production build:

```bash
npm run build
npm run preview
```

## Before sharing with prospective clients

1. Add a working professional email address or a form that actually sends enquiries.
2. Replace concept projects with genuine client work as it becomes available, keeping fictional work clearly labelled.
3. Add real testimonials only with permission.
4. Verify all live links and test the site on a phone and desktop.
5. Agree on project scope, timeline, and price before starting client work.
